# Contributing to github-profile

Thank you for your interest in contributing to **github-profile**! We welcome bug reports, feature suggestions, documentation updates, and code contributions.

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## Getting Started

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/shauryamalhotra957-wq/github-profile.git
   cd github-profile
   ```
3. **Set up the development environment**:
   ```bash
   # Follow repository-specific setup
   ```

## Development Workflow

1. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. Make your modifications, keeping commits atomic and commit messages clear and imperative (e.g. `feat: add telemetry stream parser`).
3. Run tests and verify:
   ```bash
   # Run tests or validation scripts
   ```

## Submitting a Pull Request

1. Push your branch to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
2. Open a Pull Request against `main` or `master`.
3. Complete the [Pull Request Template](.github/PULL_REQUEST_TEMPLATE.md).
4. Ensure CI checks pass. Maintainers will review your PR and provide feedback.
